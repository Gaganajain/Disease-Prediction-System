# Disease Prediction System

## 📌 Project Overview
This project predicts diseases based on patient symptoms using Machine Learning ensemble models and healthcare data analysis.

---

## 📌 Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Tkinter
- Matplotlib
- Seaborn

---

## 📌 Machine Learning Algorithms
- Random Forest
- Logistic Regression
- Naive Bayes
- Support Vector Machine (SVM)
- Ensemble Voting Classifier

---

## 📌 Features
- Disease Prediction
- Symptom Analysis
- GUI-based Prediction System
- Ensemble Learning
- Risk Classification
- Accuracy Comparison
- Confusion Matrix

---

## 📌 Dataset
Healthcare dataset containing:
- Age
- Gender
- Symptoms
- Disease labels

---

## 📌 Output
The system predicts possible diseases with confidence scores and risk levels using machine learning models.

Generated Outputs:
- Disease Distribution
- Symptom Analysis
- Heatmaps
- Confusion Matrix
